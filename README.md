# inSpiRe Medical Coding Institute Website

Multi-page HTML/CSS/JavaScript website.

## Start
Open `index.html` in a browser, or serve the folder using VS Code Live Server.

## Pages
Home, About Us, Courses, Speciality Trainings, Why Us, Placements, Contact, and four course detail pages.

## Institute video
`assets/videos/institute.mp4` is used ONLY on the homepage hero. The video is muted, autoplaying, looping, and plays inline.

## Enquiries
The contact form currently prepares an email using `mailto:`. For actual online submissions, connect a secure backend or form service before launch.

## Before publishing
Replace placeholder descriptive content with institute-approved copy, verify course details and placement claims, check Google Maps directions, and test on mobile devices.
